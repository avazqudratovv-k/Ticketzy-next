# Changelog

Ticketzy was migrated from `nestar-next`; the old Nestar changelog was removed because none of it applies. Git history is the full log. What was decided is in `docs/ai/DECISIONS.md` and what was done is in `docs/ai/FRONTEND_COMPLETED_TASKS.md`.

## 0.1.0

First Ticketzy version number (Nestar's 2.2.0 was dropped).

- Buyer flow: events, seat picking, simulated checkout, orders and tickets.
- Organizer and admin dashboards, venue editor, check-in, messaging and the assistant.
- Four languages (en, ko, ru, uz), dark and light themes.
- Global session-expiry handling, safe `returnTo`, CI.
- Removed unused Nestar leftovers: `sweetalert2`, `animate.css`, `@mui/icons-material`, `standard-version`, `public/img`.
